# AMC Global Media (formerly AMC Networks)

> AMC Global Media Inc. (NASDAQ: AMCX) is a global entertainment company that owns and
> operates AMC, BBC America, IFC, SundanceTV, We TV and IFC Films, the AMC+, Acorn TV,
> Shudder, Sundance Now, HIDIVE and ALLBLK streaming services, AMC Studios, and AMC
> Networks International. It distributes 33 FAST channels across 22 platforms and sells
> advertising through the Audience+ data platform and AMCN Outcomes measurement product.
> The company rebranded from "AMC Networks" to "AMC Global Media" in 2026;
> www.amcnetworks.com now redirects to www.amcglobalmedia.com.

## API status (verified 2026-09-02)

AMC Global Media publishes **no public developer program and no machine-readable API
contract**. There is no developer portal, no OpenAPI/AsyncAPI/GraphQL/WSDL/gRPC
definition, no SDK on any public package registry, no MCP server, and no A2A agent card
on any host the company controls. Integration with the company is commercial and
bilateral: affiliate distribution through a login-gated partner portal, advertising
through a sales conversation, and broadcast delivery through its Broadcasting &
Technology group.

Agents should not expect a callable AMC Global Media endpoint. Treat the surfaces below
as human-facing web pages and business contacts, not as an API.

## Partner and commercial surfaces (all gated, no public API)

- [Affiliate Portal](https://affiliate.amcnetworks.com/): Login-gated partner portal — marketing materials, key art, promotional video, social toolkits, legal certifications and technical launch documents for cable and streaming distributors.
- [Connect (Ad Sales)](https://connect.amcglobalmedia.com/): Advertising sales entry point covering Audience+ audience segmentation and AMCN Outcomes measurement. No self-serve API; campaigns are booked through sales.
- [Press Center](https://press.amcglobalmedia.com/): Credentialed press assets; the public entry redirects to a login.
- [Technical Services](https://www.amcglobalmedia.com/technical-services/): AMC B&T program origination, encoding, satellite uplink and studio production. Transmission requests go through a login at toc.amcnetworks.com — an operations portal, not a developer API.

## What was checked and did not exist

- /openapi.json, /swagger.json, /api-docs on www.amcnetworks.com, www.amcglobalmedia.com and affiliate.amcnetworks.com — 404 on all.
- /.well-known/security.txt, /openid-configuration, /oauth-authorization-server, /api-catalog, /ai-plugin.json, /agent-card.json, /agent.json — 404 on every AMC-controlled host.
- /llms.txt — 404 on every host (this file is generated by API Evangelist, not published by AMC).
- api.amcnetworks.com, developer.amcnetworks.com, api.amcplus.com — no DNS.
- status.amcnetworks.com, status.amcglobalmedia.com, status.amcplus.com — no DNS; no status page.
- npm, PyPI — no first-party AMC client library published.
- No public GitHub organization for the company.
- The only JSON API served on an AMC host is the incidental WordPress REST root at
  www.amcglobalmedia.com/wp-json/ (WordPress core, oEmbed and Gravity Forms namespaces).
  That is CMS plumbing shipped by WordPress, not a product API AMC publishes, documents
  or supports, so it is not listed as an AMC API in this profile.
